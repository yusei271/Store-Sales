# Store Sales Time-Series Forecasting

A machine learning project for the Kaggle Store Sales - Time Series Forecasting competition. The goal was to predict daily sales for different product families across Favorita stores in Ecuador.

## Overview

This was a two-person project in which I led the technical implementation of the forecasting pipeline. The project involved integrating multiple datasets, preprocessing more than 3 million sales records, engineering time-series features, training gradient boosting models, and generating predictions for Kaggle submission.

## Technologies

- Python
- Pandas
- NumPy
- LightGBM
- scikit-learn
